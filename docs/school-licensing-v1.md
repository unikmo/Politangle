# Politangle School — Licensing Amendment v1

Status: **CANONICAL PRODUCT AMENDMENT — effective 2026-09-08.**

This amendment supersedes any earlier School specification that requires a QR code or permits an unlicensed teacher to create a classroom.

## Commercial rule

- One school pack costs **$300**.
- One school pack provides **10 teacher licenses**.
- Each licensed teacher is given a distinct teacher license credential.
- The billing/renewal period has **not been specified**. Do not infer monthly, annual or perpetual entitlement until a separate pricing decision is made.

## License vs session code

These are different credentials with different purposes.

### Teacher license

- Issued as one of the school's 10 licensed teacher seats.
- Required before a teacher can create a classroom.
- Not shown to students.
- Does not identify or profile students.
- In the current lightweight architecture, it does not require a teacher account.

### Classroom session code

- Generated by a licensed teacher for a specific classroom session.
- Short-lived classroom onboarding credential for students.
- Students enter the code directly; **QR code is not required**.
- Student participation remains anonymous and does not require a name, email, username or student ID.

## Current implementation model

- Raw teacher license credentials are not persisted in Firestore; the server stores a SHA-256 document identifier derived from the normalized credential.
- A validated teacher license is carried as an HTTP-only, secure, same-site browser-session cookie.
- Classroom creation re-validates the license server-side and increments aggregate session usage for that license.
- New classroom records retain the school ID and hashed teacher-license document ID for operational attribution, not teacher identity.
- A revoked teacher license cannot create a new classroom.

## Provisioning

The non-production/admin provisioning command is:

`npm run school:provision-license-pack -- --school-id school-slug --school-name "School Name"`

It creates one school account record and exactly 10 distinct teacher license records, then prints the 10 raw credentials once for controlled distribution.

The command refuses to silently overwrite an existing school account or regenerate its credentials.

## Deliberately not implemented yet

- payment checkout/billing automation;
- renewal/expiry rules;
- school administrator portal;
- named teacher accounts;
- automatic reassignment of a seat from one teacher to another;
- strict device binding or prevention of deliberate license sharing.

These are later operational controls, not prerequisites for validating the School classroom product.

## Privacy rule unchanged

The teacher license changes who may **create** a classroom. It does not change classroom privacy:

> **The teacher sees the room, never the individual student.**

No teacher-facing student-to-answer mapping is introduced by licensing.
