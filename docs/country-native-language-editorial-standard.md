# Politangle country-language editorial standard

**Status:** enforced editorial standard for country perspectives  
**Applies to:** German, Spanish and French country-language versions

Politangle country-language versions are **not sentence-by-sentence translations of English**.

Each language version must:

1. express the same verified political and institutional facts in natural target-language prose;
2. use terminology a politically literate native reader would expect in that language;
3. preserve formal local institution names when translating them would distort meaning, while explaining them naturally where needed;
4. avoid importing English political labels when a normal target-language equivalent exists;
5. explain terms such as liberal, republican, conservative, federalism, devolution, populism and party-family labels in their country-specific meaning rather than assuming a one-to-one translation;
6. allow sentence order and explanatory emphasis to differ from English when that improves clarity;
7. preserve source provenance and not introduce new current political facts during language editing;
8. receive cross-language factual-consistency checks after editorial rewriting.

## Review status

The repository's language pass is an **internal native-style editorial review**, not certification by an external human native-language editor. Politangle must not describe it publicly as independently human-reviewed unless that review later occurs.

## Regression rule

A future content update must not overwrite a natural target-language version with machine-style or literal English mirroring merely because the English source changes. Facts should be reconciled first; wording should then be edited natively in each language.
