# Politangle localization editorial standard

## Governing rule

Each language is written as original product copy for that audience. English sentence structure is not the template. A localized page must sound as though it was conceived in the target language.

## German voice

- Use natural contemporary standard German and consistent informal `du`.
- Prefer short, direct sentences and familiar verbs.
- Explain specialist political terms before using them as interface labels.
- Keep product names such as `Quick`, `Full`, `CLASSIFY` and `UNDERSTAND` only where they identify a distinct Politangle product or mode.
- Do not preserve English metaphors or syntax when a German reader would phrase the idea differently.
- Avoid compressed compound nouns, nominal style and internal product language in public copy.
- Translate concepts by meaning, not word shape. For example, `civic membership` is not `bürgerliche Zugehörigkeit`; the intended meaning is equal belonging through citizenship.
- Calls to action must say exactly what happens next: `Quick-Test starten`, `Zum Glossar`, `Länder entdecken`.
- Privacy and validation copy must remain precise, but precision is not a reason to sound bureaucratic.

## Review gate

Before a language is described as complete:

1. Read the full journey in that language without comparing it line by line with English.
2. Check the homepage, navigation, assessment, results, learning tools, country pages, School, account, legal and error states.
3. Remove untranslated fallbacks and mixed-language labels.
4. Check terminology across pages so the same concept does not receive several accidental translations.
5. Read headings, calls to action and explanations aloud for rhythm and ordinary usage.
6. Verify all localized routes, metadata and `hreflang` links.

German is the first language to pass this editorial gate. Spanish, French and Brazilian Portuguese follow as separate rewrites, not as copies of the German version.
